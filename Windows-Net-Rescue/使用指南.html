WINDOWS NETWORK RESCUE · V2.1

断网时，先定位问题，再针对性处理

无需安装依赖。自动检查常见网络故障，执行有证据支持的处理，再复测并显示结果。

怎么运行覆盖范围Clash 使用习惯恢复与记录

从这里开始

  1. 把整个 Windows-Net-Rescue 文件夹从 NAS 复制到 Windows 桌面；若使用 ZIP，先全部解压。
  2. 先双击 CHECK-ONLY.cmd：只检测并显示拟修复方案，不会执行修复。
  3. 需要先确认再修复时，运行 PREVIEW.cmd。看清对象、步骤和影响后，在命令窗口输入大写 APPLY 才执行；直接回车退出。
  4. 若 PREVIEW.cmd 提示需要管理员权限，右键 PREVIEW.cmd，选择“以管理员身份运行”。仍须重新检测、预览并确认。
  5. 工具会尝试打开本地 HTML 结果页。按页面说明操作，并重新打开浏览器或语音软件验证。
CHECK-ONLY.cmd 永不进入修复；PREVIEW.cmd 只有收到 APPLY 才执行对应方案。此 HTML 页面是离线说明，无法批准修复。
如需只读诊断和手动选项，运行 START.cmd。

每次双击只运行一轮，不安装后台常驻任务。检测可能需要数分钟。若 UAC 要求另一个账户的密码，代理设置会对应那个运行账户，请留意。

预览和执行清楚分开

预览显示检测依据、拟处理对象、准备执行的步骤、影响、恢复方式及是否需要管理员。所有拟操作都标为“尚未执行”。

执行前重新检测；方案或目标变化会停止，要求重新预览。修好一层后若发现另一类故障，也需要重新确认。

AUTO-FIX.cmd 保留为原来的无人确认自动修复入口，可能直接处理故障。测试正常网络请选择 CHECK-ONLY.cmd；想控制执行请选择 PREVIEW.cmd。

自动检查什么，怎么处理

层次检查线索对应处理
WiFi / 网卡无网卡、未连接、禁用提示连接 WiFi、启用网卡或检查驱动
网络服务原本自动启动的 WLAN / DHCP / DNS 服务意外停止按条件启动服务，并回读状态
IP / DHCP自动地址无效、无网关、Windows 报告地址冲突只为明确的那张网卡续租
网关 / 路由 / IPv6本地网关、默认路由、VPN 拆分路由给出热点对照和路由检查建议
DNS两个域名，默认与公共 DNS 对照清缓存；符合条件时备份后试用可达 DNS
本地代理直连正常，系统路径失败，本地代理端口不可达客户端已退出时，备份后关闭残留手动代理
网页认证HTTP 重定向或测试内容改变提示打开认证页面，账号由你填写
时间 / HTTPS证书错误、两处服务器时间提示本机时钟偏差按条件请求原 Windows 时间源同步
hosts / WinHTTP / VPN自定义映射、系统级代理、环境变量和 VPN 线索保留可能有用途的配置，给出操作建议
宽带 / 驱动 / 硬件无法由软件单独确认的外部故障提示手机热点对照、路由器和驱动检查

DNS 和代理改前备份、改后回读；复测无效时，在没有其他程序改动的前提下尝试恢复。正常代理、多网卡、组织域、手动 IP/DNS 等场景会保留设置。重新申请 DHCP 可能短暂改变局域网连接；时间同步可能调整时钟。服务、续租和时间同步不属于可用菜单 5 撤销的配置备份。

以后继续使用 Clash Verge

  1. 需要时开启 Clash 的系统代理，确认代理可以工作。
  2. 用完先关闭系统代理，再从右下角托盘菜单选择退出。
  3. 如果启用了系统代理守卫，手动关代理前可先关闭守卫，避免它在软件仍运行时重新开启代理。
  4. 遇到崩溃或异常断电后的断网，运行 AUTO-FIX.cmd。工具会保留正在运行的代理客户端，必要时提示你先正常退出。

主窗口关闭不一定代表程序退出。Clash Verge Rev 官方 Windows 常见问题记录了系统代理残留的情况。

记录留在电脑上，随时可以核对

报告与可视化结果：%LOCALAPPDATA%\Windows-Net-Rescue\Reports

代理与 DNS 备份：%LOCALAPPDATA%\Windows-Net-Rescue\Backups

需要恢复时：START.cmd → 菜单 5。v1 和 v2 共用备份目录，旧版备份仍可使用。

工具不会上传报告、关闭防火墙、删除 WiFi 密码、自动卸载驱动或自动重启。报告可能含局域网地址或代理配置，分享前请检查。v2 新增自动修复已做语法与模拟测试，尚未在真实 Windows 上验证。

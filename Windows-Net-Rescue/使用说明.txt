Windows 断网诊断与修复工具 v2.2
Windows 10 / Windows 11；使用自带 Windows PowerShell 5.1，无需安装依赖。

一、日常怎么用

把整个 Windows-Net-Rescue 文件夹从 NAS 复制到 Windows 桌面。
也可以复制 ZIP 后“全部解压”，不要在压缩包里直接运行。

CLEAN-REPORTS.cmd：用完后清理报告。先显示范围，输入 CLEAN 才移入回收站；
                   不执行检测，不生成新报告，不删除代理/DNS 恢复备份。
CHECK-ONLY.cmd：严格只检测，显示判断、拟修复对象、步骤和影响，生成 HTML；
                不会询问执行修复，更不会修改网络配置或清 DNS 缓存。
PREVIEW.cmd：先只读检测并显示同样的方案。在命令窗口输入大写 APPLY
             才进入修复；直接回车或其他输入则退出，不修改网络配置。
AUTO-FIX.cmd：原来的无人确认自动修复入口，可能直接执行处理。只想测试时
              请用 CHECK-ONLY.cmd，需要先批准时请用 PREVIEW.cmd。
START.cmd：先只读诊断，再由你选择操作；菜单 8 也能自动修复。
使用指南.html：离线可视化说明，双击可阅读，不会执行系统修改。

建议先双击 CHECK-ONLY.cmd 测试。网络正常会显示无需修复；有问题时显示
准备如何处理，但不会执行。想确认后修复，改用 PREVIEW.cmd 重新检测。
若 PREVIEW.cmd 提示需要管理员权限，关闭窗口，右键 PREVIEW.cmd 选择
“以管理员身份运行”，重新检测和预览后仍须输入 APPLY，不会继承旧确认。
诊断可能需要数分钟；遇到多个连续故障时需要更久。
操作完成会尝试打开 HTML 结果页；若浏览器未弹出，用下面路径找 HTML：
%LOCALAPPDATA%\Windows-Net-Rescue\Reports

CHECK-ONLY.cmd 只发送测试请求、读取状态、保存报告；代理、DNS、IP、服务、
系统时间均不改变。检测本身可能产生系统正常的网络缓存，不会主动清缓存。
报告集中在 Reports 下每次运行的独立目录，不会创建网络配置备份。
正常退出时默认保留最近 3 次可管理记录，较旧记录移入回收站；
这里的“只读”指网络设置，报告生成和历史记录整理仍会进行。
PREVIEW.cmd 的确认仅对应当前显示的对象和方案，执行前重新检测；方案、
目标或关键配置变化就停止，不复用旧报告执行。修好一层后如果发现另一类
故障，会要求重新预览确认。DNS 方案会明确列出清缓存及有条件试用的地址，
清缓存后拟用地址变化会停止，不会擅自更换到未确认的地址。
HTML 页面只展示结果，无法替你输入 APPLY 或批准修复。
一次运行结束后退出，不安装后台任务，不常驻，不自动联网下载更新。
正常联网时不需要运行，不会因为安装了 Clash 就自动关闭它。

如果 UAC 要求另一个账户的密码，运行账户会改变，代理设置也对应那个
账户。请先普通运行处理自己的代理，再用管理员模式处理其他网络问题。
若单位策略禁止脚本，不要改全局执行策略绕过管控。

二、自动模式的覆盖范围

1. WiFi/网卡：识别无网卡、未连接、禁用等线索，提示打开 WiFi、关闭
   飞行模式、连接网络、检查设备管理器和驱动。不会猜 WiFi 或密码。
2. 网络服务：家庭非组织域电脑、无运行中代理/VPN 干预时，可启动
   原本设为“自动”但已停止的 WLAN/DHCP/DNS 服务；不修改启动类型。
3. IP/DHCP：唯一连接的真实网卡使用自动 IP，但没有有效地址/网关，
   或 Windows 报告地址冲突时，可对这一张网卡执行 DHCP 续租。
   不先释放地址、不改静态 IP。续租可能短暂影响 NAS/局域网连接。
4. 网关/路由/IPv6：收集网关、默认路由、拆分默认路由与 IPv6 信息；
   用公网 IP 的 TCP 测试辅助区分域名解析与外网路径。不自动删路由。
5. DNS：两个域名默认查询均失败，同一公共 DNS 对两个域名均成功，
   复测仍然符合条件时，先清缓存。仍不通且网卡/路由明确时，可备份
   后仅调整所选网卡 IPv4 DNS。只采用实际通过测试的阿里公共 DNS。
   自动模式保留手动 DNS、手动 IP、多网卡、虚拟网卡和组织域配置。
   公共 DNS 试用后网页测试未通过，会在配置未被他人改动时恢复自动 DNS。
6. 代理/Clash：两个网站直连均成功、系统路径均失败，本地手动代理
   端口连续两次不可达，且相关代理/VPN 进程已退出时，备份后关闭
   手动代理开关，保留代理地址和绕过列表。复测无效会尝试恢复。
   正常工作的代理、仍在运行的客户端、远程代理和 PAC 不会自动关闭。
7. 认证网页：HTTP 被重定向或测试内容改变时，提示打开认证页面。
   这是疑似认证/拦截线索，工具不能替你完成登录。
8. 时间/HTTPS：收集证书和安全通道错误。两处服务器日期相互吻合、
   都提示本机时间明显偏差时，可请求 Windows 使用原 NTP 时间源同步。
   不直接照网页时间改钟，不更换时间源。同步可能调整系统时钟。
9. hosts/WinHTTP/环境变量：识别相应线索并给具体建议；这些设置可能
   有合法用途，自动模式不清空 hosts、不删除环境变量或系统级代理。
10. VPN、驱动、防火墙、宽带/路由器：收集线索，提示手机热点对照、
    退出 VPN、检查驱动或路由器设备限制。不会关闭防火墙、卸载驱动。

自动修复有次数限制，不会反复续租或重试结果不确定的命令。
DNS/代理写前备份、写后回读；复测失败或异常时，仅在当前配置仍属于
本次修改的情况下尝试恢复，避免覆盖其他软件正在作出的修改。
服务启动、DHCP 续租、请求时间同步不属于可用菜单 5 撤销的配置备份。
工具不保证修复运营商故障、WiFi 密码错误、硬件损坏或所有应用独立配置。

三、HTML 结果怎么看

绿色：两个指定网站的 Windows HTTPS 路径通过，可能是原本就正常，
或本次处理后通过。请重新打开实际浏览器和语音软件验证。
其他结果会说明需要管理员、需要连接 WiFi、需要网页认证、尝试后已恢复
原配置，或还存在问题并给出下一步操作。通常不需要把报告发给别人分析。

浏览器自己的安全 DNS、插件、独立代理和应用特定网络设置不一定与本工具
相同。Ping 不回应也不等于断网，单个地址失败不能证明外网完全不可达。
若家庭 WiFi 不通而手机移动热点正常，重点检查家庭路由器/宽带；
若热点也不通，重点检查这台电脑的 VPN、时间、过滤软件及驱动。

四、手动菜单与恢复

START.cmd：1 重新诊断；2 清 DNS 缓存；3 关闭当前用户手动代理/PAC；
4 手动选择网卡改 IPv4 DNS；5 恢复 DNS/代理备份；6 高级 Winsock 重置；
7 打开报告目录；8 无人确认自动修复；9 只读预览并确认后修复；
10 清理历史报告；0 退出。

菜单 6 不会自动执行，可能影响 VPN/安全软件组件，需手动重启，
它的目录记录仅供诊断，不能当作可恢复备份。

用完后怎样清理：
先退出其他检测窗口，普通双击 CLEAN-REPORTS.cmd，无需管理员。
检查列表后输入 CLEAN，把本工具的报告移入回收站；回车取消。
它兼容旧版 Reports 中的已知文件，不处理其他文件或目录。
新版报告按次归档，自动保留最近 3 次；运行中/混有其他内容的记录保留。
Backups 是恢复原代理/DNS 用的，始终保留，不需要你分辨哪些备份该删。
清理入口不会制造新的清理报告；回收站失败则保留原件。
工具文件夹、桌面资料、NAS 上的副本不在清理范围内。

报告：%LOCALAPPDATA%\Windows-Net-Rescue\Reports
备份：%LOCALAPPDATA%\Windows-Net-Rescue\Backups
新旧版共用以上位置，因此仍能从 v2 菜单 5 恢复 v1 的代理/DNS 备份。
修改 DNS 后，如果 NAS 按名称无法访问，可先改用 NAS 的 IP，或恢复备份。
删除工具目录不会撤销已经修改的配置，请按需要先恢复。

五、继续使用 Clash Verge

需要时打开 Clash Verge 的“系统代理”，确认代理服务可用。
用完先关闭“系统代理”，再从右下角托盘菜单“退出”，不要只关主窗口。
若启用了“系统代理守卫”，它可能在软件仍运行时重新开启系统代理；
临时手动关闭代理前，可先在 Clash 中关闭守卫，避免与工具互相改设置。
崩溃、断电、强制结束进程等仍可能留下代理开关，无法完全靠正常退出避免；
以后遇到断网，可运行 AUTO-FIX.cmd。不要为了解决残留而自动终止所有 VPN。

六、隐私和验证范围

工具不会上传报告或备份，不读取 WiFi 密码。诊断会向百度、腾讯、微软
和公共 DNS 地址发送少量常规请求。日志可能含本地地址、WiFi 名称、代理
URL、hosts 条目，分享前请检查并遮盖令牌等信息。

v2.2 已在 macOS 上做 PowerShell 语法与隔离模拟测试，以及 HTML 转义检查。
新增测试覆盖：各类故障只读预览零修改、拒绝/回车不修复、明确确认后执行、
旧方案失效、修复对象变化、DNS 目标变化、权限不足和不扩大后续修复范围。
报告清理的范围、保留和失败处理使用临时目录模拟测试；Windows 回收站
实际移动尚未实机验证。尚未在真实 Windows 上验证本版新增的自动修复，不保证所有电脑均兼容。
v1 的手动代理关闭功能已在最初案例的 Windows 电脑上成功使用。
启动器的 ExecutionPolicy Bypass 仅用于本次 PowerShell 进程，不改变全局
执行策略，不下载远程脚本。不支持 Windows 7/8 的兼容性保证。
